This activity explores the use of color palettes and typography to create attractive and readable designs.
Through this activity, I learned how to choose appropriate color combinations and fonts to create visually appealing and readable designs. One challenge I encountered was finding colors and font styles that complemented each other without making the design look crowded. I overcame this by exploring different combinations and considering readability and consistency. In the future, I can use these skills when creating presentations, infographics, and other digital materials.
