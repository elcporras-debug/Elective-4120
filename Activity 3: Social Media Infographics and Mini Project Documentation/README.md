This activity focuses on creating informative social media infographics and documenting a mini project.
This activity taught me how to present important information through infographics and organize ideas through project documentation. I learned that visual communication can make information easier to understand, especially when dealing with complex topics. One challenge I faced was selecting the most important details and presenting them in a clear and organized way. I addressed this by simplifying the information and arranging the content properly. I can apply these skills when creating health education materials and nursing-related information campaigns.
